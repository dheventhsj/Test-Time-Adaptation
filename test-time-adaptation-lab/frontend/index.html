RESEARCH QUESTION

What are we measuring?

How much accuracy lost to Gaussian-noise shift can be recovered by adapting a pretrained CNN at test time, using only unlabelled noisy inputs?

iTarget labels are withheld during adaptation and used only after predictions to calculate evaluation metrics.

IMPLEMENTATION SCOPE

What this repository actually runs

The interactive experiment implements source-only inference, a BatchNorm-statistics-only ablation, and TENT. Test-Time Training and test-time prompt tuning are included as explanatory reference methods only; they are not implemented in this case study.
